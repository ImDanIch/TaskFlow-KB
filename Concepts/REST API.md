# REST API

REST API — це спосіб взаємодії програм через HTTP-запити.

У проєкті TaskFlow REST API використовується для керування завданнями.

## Основні HTTP-методи

- GET — отримання даних.
- POST — створення завдання.
- PATCH — часткове оновлення.
- DELETE — видалення.
