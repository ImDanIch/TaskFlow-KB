# SQLite

SQLite — легка реляційна система керування базами даних, яка зберігає інформацію у локальному файлі.

## Використання в TaskFlow

У TaskFlow SQLite зберігає завдання користувача у файлі taskflow.db.

Взаємодія з базою даних здійснюється через SQLAlchemy.

## Основні особливості

- Не потребує окремого сервера бази даних.
- Зберігає дані між перезапусками застосунку.
- Підходить для невеликих локальних проєктів.
- Підтримує транзакції та обмеження цілісності.
